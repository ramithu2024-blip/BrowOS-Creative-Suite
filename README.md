# BrowOS Creative Suite

Standalone browser-based creative applications from the ArtCraft/Craft App Suite.

No backend, Node.js or Go required. Deployed via GitHub Pages.

## Applications
PhotoCraft, VectorCraft, FilmCraft, LightCraft, PdfCraft, EffectCraft, DesignCraft, FigCraft, WordCraft, SoundCraft, DeckCraft, CADCraft, GridCraft, TextureCraft, Craft Anything.
